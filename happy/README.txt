ASMlTA BIRTHDAY SURPRISE — QUICK GUIDE

FILES
- index.html: the mobile-friendly birthday webpage.
- marathi-song.mp3: optional music file you add yourself.

PREVIEW ON YOUR PHONE OR LAPTOP
1. Extract the ZIP file.
2. Open index.html in a browser.
3. The page works without music. The music button appears after the surprise is opened.

ADD MARATHI MUSIC (OPTIONAL)
1. Choose an audio file you have permission to use.
2. Rename it exactly to: marathi-song.mp3
3. Put it in the same folder as index.html.
4. Upload both files when publishing.
Browsers usually require the visitor to tap the music button before sound starts.

GET A SHAREABLE LINK USING GITHUB PAGES
1. Sign in to GitHub and create a new public repository, e.g. asmita-birthday.
2. Upload index.html (and marathi-song.mp3 if you added it).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose “Deploy from a branch”.
5. Select branch “main” and folder “/(root)”, then Save.
6. Wait a minute or two. GitHub will show a website link like:
   https://YOUR-USERNAME.github.io/asmita-birthday/
7. Open that link on your phone to test it, then send it to Asmita.

IMPORTANT
- Don't include private details you wouldn't want shared; anyone with the public link can view the page.
- Music file size and copyright rules may affect hosting. You can leave music out and the surprise still works.
